# Highlander Alert for TF2Center

I don't own a second monitor, and I am tired of alt-tabbing every 2 minutes to check if a HL lobby has been created so I made this.
When a new highlander lobby is created you will be alerted by a bell sound.

**THIS IS NOT AN AUTO-JOIN BROWSER EXTENSION**

## Install
 
### Chrome, Edge, Brave (and other Chromium browsers)
 
1. Download this repository: click **Code → Download ZIP** (or grab the zip from the [Releases](../../releases) page) and unzip it.
2. Open `chrome://extensions` (`edge://extensions` in Edge).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder (the one that contains `manifest.json`).
5. Open or refresh the TF2Center lobbies page.
Chromium browsers may show a "disable developer mode extensions" notice on startup. This is normal for extensions loaded this way.
 
### Firefox
Manual installation of this extension sucks on Firefox because temporary add-ons are removed when Firefox closes (which means you'll need to repeat this each session), but here are the steps anyway: 
1. Download and unzip this repository.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on** and select `manifest.json`.
